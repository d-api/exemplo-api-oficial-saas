Conectar WhatsApp API Oficial

Exemplo mínimo de como o seu SaaS conecta o número oficial do WhatsApp de um cliente, usando a D-API como provedor. Preencha e clique em conectar — abre um popup da D-API que faz todo o Embedded Signup.

Guarde o connectionId e associe ao seu cliente. O envio de mensagens é feito no SEU backend com a sua API key secreta — nunca a exponha no navegador.
